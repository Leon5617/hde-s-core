# HDE-S-Core
Tiny Q16.16 fixed-point PID core, &lt;1KB RAM, ~4KB Flash, ISR-callable, no float in control path. Looking for embedded C partner.

## Author note
This project is built by a self-taught developer without formal CS background.
The implementation is experimental. All feedback, code review and constructive criticism are highly welcomed.
